# Sakthi Auto Component Limited — Change Management System (Frontend)

## Environment Setup
Copy `.env.example` to `.env`:
```env
REACT_APP_API_URL=http://localhost:5000
```

## Run Standalone Frontend
```bash
npm install
npm run dev
```
